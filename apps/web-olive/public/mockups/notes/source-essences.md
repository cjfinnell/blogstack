# Source essences → mockup coverage

One statement per source, under 20 words, at the level of the *idea* rather than the feature. Then: which mockup carries it. Three new mockups (E, F, G) were built to close gaps nothing in A–D covered.

Mockups: **A** Table d'Olive · **B** Brine & Ink · **C** Service · **D** Maria Eleni · **E** Unscored · **F** The Map · **G** Plain

## Gaps that forced new mockups

Six essences had no home in A–D. Each one is a genuine fork in the design, not a missing widget:

1. **"Abolish the score"** (Eater, Bon Appétit) — every one of A–D showed a number. → **E — Unscored**
2. **"Judge cooking and room separately, never averaged"** (Michelin) — A–D all collapse to a composite. → **E**
3. **"Authority as homepage furniture"** (Serious Eats) — nowhere. → **E**, echoed in **G**
4. **"The index is a map"** (Eater maps, Michelin map view, Maria's pins project) — nowhere, despite being the one project Maria already has running. → **F — The Map**
5. **"Expose the whole library at once"** (The Kitchn) + **"reader-built lists"** (Half Baked Harvest) — nowhere. → **F**
6. **"Strip the chrome; one typeface, one loud accent"** (Chef Chloe, Zacchary Bird, Infatuation's rebrand, Rosewood) — D drifted chrome-heavy as features accumulated, so Maria's own top reference lost its purest expression. → **G — Plain**

## The seven, in one line each

- **A — Table d'Olive** · warm print revival; asymmetric grid, oversized rating in the margin, archive resurfacing.
- **B — Brine & Ink** · editorial brutalism; the archive as a ruled numbered ledger with a glyph vocabulary.
- **C — Service** · dark, dinner-lit, all-serif; single column, full-bleed photography, standing columns.
- **D — Maria Eleni** · her sketch, built: script wordmark, bow, ivory and navy, seven-axis ethics rubric.
- **E — Unscored** · no numbers anywhere; cooking and room judged separately, in words.
- **F — The Map** · the index is a map of every place she has eaten, with a keyboard-navigable list beside it.
- **G — Plain** · one typeface, one loud accent, two nav links; the writing and the photographs carry everything.

**Still open:** E and G both argue against the rubric that D is built around. If Maria wants the ethics scoring, D or B is the direction. If she wants Chef Chloe, G is the honest version of that — and the rubric becomes prose.
